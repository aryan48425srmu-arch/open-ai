# Open AI

A simple starter repository for building OpenAI-powered apps.

## Features

- Python app template
- OpenAI client integration
- Plan folder for Copilot feature work

## Quick start

1. Create a virtual environment
2. Install dependencies
3. Set your API key:
   ```bash
   export OPENAI_API_KEY="your_key_here"
   ```
4. Run the app:
   ```bash
   python app.py
   ```
